Foot & Height Explorer

Interactive lesson visualization of the relationship between foot length and
height in the provided FootVSHeight.csv dataset (200 observations).

Live site: https://mjqsk.github.io/FootHeightExplorer/

Includes a fitted regression line, a prediction slider, 95% confidence and
prediction intervals, residual inspection, a guided walkthrough, and SVG export.
The HTML embeds its data, fonts, and Plotly runtime and also works offline.

Units are not specified in the source. Association does not establish causation.

GitHub Pages serves index.html from the root of the main branch.
The build source and analysis remain in the local lesson workspace.
